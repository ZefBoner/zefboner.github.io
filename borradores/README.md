# Borradores privados

Esta carpeta es tu zona segura. Todo lo que pongas aquí **NO** se sube a GitHub (está en
`.gitignore`) ni se publica en el sitio (está excluida en `_config.yml`).

Úsala para writeups de máquinas, Sherlocks o CTFs que **todavía están activos** y no puedes
publicar aún. Cuando el contenido se retire o el evento termine, mueve el archivo a `_posts/`
(con el nombre `AAAA-MM-DD-titulo.md`) y publícalo.

> Recuerda: el repositorio de GitHub es público. No pongas writeups de contenido activo
> directamente en `_posts/`; déjalos aquí mientras tanto.
